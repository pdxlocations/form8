Install or update Form8

Use this page to install Form8 software on your radio over USB. Choose the version and board below, download the software, then connect to the radio to install it.

Form8 lets you exchange incident forms and short chat messages between LoRa radios using a phone or laptop. Once installed, messaging works without internet or cell service. Radio messages are not encrypted.

Project information and source code on GitHub ↗

What you need

  • A computer using Chrome or Edge, with internet access for the download.
  • A supported radio and a USB data cable. A charging-only cable will not work.
  • The exact board model and radio chip. Check the board markings or the board guide if unsure.

Plug in the radio and close any serial monitor or other app using its USB port.

After installation

  1. Find the radio’s Wi-Fi name and password. These appear on its screen after it restarts. If the board has no screen, open Logs & Console at 115200 baud and send wifi.
  2. Connect your phone or laptop to that Wi-Fi network. Stay connected even if it reports no internet access.
  3. Open http://192.168.4.1. In Radio setup, save your callsign and use matching radio settings on all participating nodes. Attach the antenna before enabling radio transmission.
My radio does not appear or will not connect

Try another data cable or USB port. If needed, hold BOOT, press and release RESET, then release BOOT and connect again. Some boards appear under a different USB port in bootloader mode. Select that port. A USB serial driver may be needed for boards with a USB-to-serial bridge.

Will this preserve my messages?

An app-only update using the same board and partition layout preserves storage when “Erase device” is unchecked. Archive important forms first. A first-install image replaces storage even if that installer checkbox is unchecked.

What if there are no builds yet?

The GitHub release workflow must finish before its builds appear here. Click Refresh releases after a few minutes. Older releases may offer updates only. The site checks GitHub at most once every five minutes.
