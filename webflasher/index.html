Before you connect

  1. Use a USB data cable. Close serial monitors and other apps using the radio. Attach its antenna before enabling radio transmission.
  2. Choose the exact board. V4.2 and V4.3 use different front ends. T3-S3 SX1262 and SX1276 have separate builds.
  3. After installation, reconnect. Read the Wi-Fi name and password on the OLED, or use Logs & Console at 115200 baud and send wifi on a headless XIAO or BPF.
  4. Open the radio’s app. Join its Wi-Fi hotspot, visit http://192.168.4.1, then save your callsign and matching radio settings.
My radio does not appear or will not connect

Try another data cable or USB port. If needed, hold BOOT, press and release RESET, then release BOOT and connect again. Some boards appear under a different USB port in bootloader mode. Select that port. A USB serial driver may be needed for boards with a USB-to-serial bridge.

Will this preserve my messages?

An app-only update using the same board and partition layout preserves storage when “Erase device” is unchecked. Archive important forms first. A first-install image replaces storage even if that installer checkbox is unchecked.

What if there are no builds yet?

The GitHub release workflow must finish before its builds appear here. Click Refresh releases after a few minutes. Older releases may offer updates only. The site checks GitHub at most once every five minutes.
